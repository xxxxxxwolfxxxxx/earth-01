Cloud-Speicher als eigene Skills

User bringt seinen eigenen Speicher mit. Jede Anbindung lehrt was Neues — OAuth, REST-File-APIs, Versionierung. Hier eine Übersicht der realistischen Optionen.

🟢 Top-3 Kandidaten

📂 Google Drive
15 GB gratis
User loggt sich einmal per Google ein, der Agent darf Dateien in einem festen Ordner ablegen/lesen. Notizen werden zu echten Google-Docs, Bilder zu echten Drive-Files.
Lehrt: OAuth-Flow, Token-Refresh, REST-API für Files.
Achtung: User braucht Google-Account. OAuth-App muss bei Google registriert sein (einmaliger Setup von dir).
🐙 GitHub-Repo
unbegrenzt (privat)
User legt ein privates Repo „mein-agent-memory" an, der Agent schreibt Notizen als Markdown-Dateien rein. Jede Änderung wird automatisch versioniert (Git-History).
Lehrt: Git-Konzepte, Commits, Versionierung, Personal Access Tokens.
Bei zu vielen kleinen Commits kann GitHub eingreifen. Geeignet für Notizen/Tagebuch, nicht für Echtzeit-Logs.
🔵 OneDrive (Microsoft)
5 GB gratis
Wie Google Drive, aber Microsoft. Wer schon einen Microsoft-Account hat (Outlook, Xbox, Office Online) muss nichts Neues anlegen. Graph-API ist gut dokumentiert.
Lehrt: OAuth-Flow, Microsoft Graph API.
5 GB ist enger als Google.

🟡 Spezial-Use-Cases

📄 Notion workspace
unbegrenzt (privat)
Agent schreibt in deine Notion-Seiten. Strukturierte Datenbanken, Markdown, geteilte Workspaces.
Lehrt: Notion API, Block-basierte Inhalte.
📊 Google Sheets tabellen
~10 Mio. Zellen
Perfekt für strukturierte Daten: Einkaufslisten, Symptom-Tracker, Finanzen. User sieht alles in Tabellenform.
Lehrt: Tabellen-APIs, Service-Account-Auth.
📎 Mega.nz große files
20 GB gratis
Größter kostenloser Speicher. Gut für generierte Bilder, Audio-Aufnahmen.
Lehrt: End-to-End-Verschlüsselung, Bandbreiten-Limits.
API ist umständlich, Bandbreite limitiert.
🟦 Cloudflare R2 profis
10 GB gratis
S3-kompatible Objekt-Speicher, keine Egress-Gebühr. Schnell wie ein CDN.
Lehrt: S3-Protokoll, Buckets, Objekt-Speicher.
Setup verlangt Kreditkarte hinterlegt (auch wenn nichts abgebucht wird) — Hürde für viele User.

🔴 Eher nicht

Dropbox
2 GB gratis
Zu klein, OAuth ist komplex. Heute kaum noch sinnvoll.
file.io / transfer.sh
temporär
Files verschwinden nach Download oder 14 Tagen. Für persistentes Gedächtnis ungeeignet.

💡 Vorschlag für den Tech-Tree

Als eigener Tier-2-Ast „Speicher anbinden" im Tech-Tree:
  • 📂 Google Drive (15 GB) — Lehr-Modul: OAuth-Flow Schritt für Schritt
  • 🐙 GitHub-Repo (unbegrenzt) — Lehr-Modul: Git-Grundkonzepte
  • 📊 Google Sheets — Lehr-Modul: API-Service-Accounts
Diese Skills sind Voraussetzung für „Großes Gedächtnis" — wer mehr als die Plattform-Standardablage will, muss eines davon anbinden.

Die Plattform bekommt automatisch einen Storage-Adapter: egal welchen Cloud-Speicher der User verbindet, der Agent nutzt eine einheitliche API. Du als Projektleiter musst nichts erweitern wenn neue Provider dazu kommen.
