Lern-Pfade statt linearer Baum

Hub im Zentrum (Trunk-Skills wie API-Keys + Telegram), dann radial 7 Themen-Pfade. Jeder Pfad ist eine eigene Lern-Reise. Skills wachsen entlang der Pfade.

🌟 Hub — Voraussetzungen für alles (API-Keys, Telegram). Hier starten alle Pfade.
🌐 Daten aus dem Netz — REST-APIs, JSON, Open Data
🛡️ Sicherheit & Privatsphäre — Hashes, Passwörter, Leak-Check
🧠 Mich selbst verstehen — Stimmung, Gewohnheiten, Tracking
🤖 Sprachmodelle — LLM-Chat, RAG, Quantisierung
⏰ Automation & Routinen — Reminder, Cron, Workflows
☁️ Eigene Cloud — Google Drive, GitHub, OneDrive
🎁 Spielerei — QR, Witze, Zitate, NASA

🎯 Was sich dadurch ändert

Statt linearem „Anfänger → Fortgeschrittener":
  • User wählt sein Interesse: „Ich will mehr Privatsphäre lernen" → klick auf 🛡️ Pfad
  • Jeder Pfad ist eigenständig nutzbar — niemand muss durch LLM-Stoff um Stimmungs-Tracking freizuschalten
  • Querverbindungen sind möglich: „Tägliches Briefing" braucht Wetter (🌐) + Reminder (⏰) + LLM-Chat (🤖) → mehrere Pfade „treffen sich"
  • Förderungs-Story wird stärker: „7 Lern-Pfade, jeder ein eigenes Curriculum mit konkretem Werkzeug-Output"
MVP-Empfehlung (Phase 1):
  • 🌟 Hub (API-Keys, Telegram) — Pflicht für alle
  • 🌐 Daten aus dem Netz — komplett (7 Skills, alle zero-token)
  • 🎁 Spielerei — 3-4 Skills für sofortige Erfolgserlebnisse
  • 🛡️ Sicherheit — Hash, Passwort-Gen, Leak-Check (Bildungs-Goldmine)
  • 🧠 Tracking — Notizen, Stimmung, Gewohnheiten
Das sind ~20 Skills. Tier 2 mit LLM-Pfad und Cloud-Speicher folgt in Phase 2.
