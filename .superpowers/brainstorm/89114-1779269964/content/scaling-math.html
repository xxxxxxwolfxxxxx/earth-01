🚧 Bottleneck identifiziert: Edge-Function-Aufrufe

Bei mittlerer Nutzung (10 Tool-Calls/Tag pro User) sind nach ~1.600 Usern die Edge-Function-Quotas erschöpft. Aber: nicht jeder User chattet täglich. Realistisch ist eine Mischung:
  • 10% Heavy-User (~30 Calls/Tag) → 9k Calls/Monat each
  • 40% Regular (~5 Calls/Tag) → 150 Calls/Monat each
  • 50% Schläfer (Account ja, kaum Aktivität) → 5 Calls/Monat each
Realistischer Mix: 500k / (0.1·9k + 0.4·150 + 0.5·5) → ~500 User bei vollem Mix, oder ~2.000-3.000 wenn Skills sparsam laufen (kein LLM bei trivialen Sachen).

💰 Wann muss Geld fließen?

Schwelle ~2.000 aktive User bei realistischer Mischung — dann erst muss man entweder:
  • Auf Supabase-Pro upgraden (25 USD/Monat → 5× alle Limits)
  • Oder Cloudflare Workers anbinden (kostet nur wenn man Pro-Workers braucht)
  • Oder Premium-Tier einführen ($1/Monat = "5x Edge-Calls Garantie")
Vorher genug Zeit für: Förderung beantragen, AdSense laufen lassen, Affiliate-Links einbauen.
